I write my to-do list in a journal every day, and I still love doing it. This project asks whether I can code my own version.

The hardest part of a to-do list, for me, is the tasks that don’t belong to a particular day, like reading an article I found online. It’s a small problem, but a good excuse to explore <Ref n={1} />.

## First release

**11 November 2025.** The goal is a minimum viable product where you can:

- create a workspace
- create and edit sprints
- create and edit tasks

Deployment comes next. I’ll keep adding releases to this post as they ship.
