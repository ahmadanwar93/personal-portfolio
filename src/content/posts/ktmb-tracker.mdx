A real-time tracker for KTMB (Keretapi Tanah Melayu Berhad) trains. Every train that reports its position shows up on an interactive map, and clicking one tells you its route, next stop and speed <Ref n={1} />.

  A train on the Padang Besar to Gemas electric service, with its next stop and last update time.
</Fig>

## How it works

The live data comes from the GTFS Realtime API, which sends vehicle positions as Protocol Buffers, a compact binary format rather than JSON. The app loads the GTFS Realtime schema into a protobuf decoder and turns that binary into readable vehicle records.

Positions alone are thin: a vehicle ID and some coordinates. So each point is enriched with the GTFS Static data (routes, stops and trips, parsed from CSV) before it lands on the map <Ref n={1} />.

## Stack

- React with TypeScript, built with Vite
- Tailwind for styling
- Leaflet for the map
- protobufjs to decode the realtime feed
- PapaParse to read the static GTFS files

## What’s next

- A GitHub Action that rebuilds the app whenever the static data is refreshed each day.
