## Why tree rings

I wanted this to sit somewhere between a chart and a piece of graphic design, which is why it looks a bit wacky. I went through a lot of ways to draw a birthday and landed on tree rings: they tell you a tree’s age, which felt close enough to a birthday. Thanks to Naz for the feedback along the way.

## More to explore

I’d like to know whether the pattern holds if you look at both the total and the average births for each day across all the years. I haven’t had time to draw it, but the code to get those numbers is below. It reads the [births CSV from the data catalogue](https://data.gov.my/data-catalogue/births).

```python
import pandas as pd

df = pd.read_csv('births.csv')
df['date'] = pd.to_datetime(df['date'], errors='coerce')

grouped = df.groupby(df['date'].dt.day)['births']

avg_births = grouped.mean().reset_index()
avg_births.columns = ['day', 'avg_births']
avg_births.to_csv('daily_births_average.csv', index=False)

sum_births = grouped.sum().reset_index()
sum_births.columns = ['day', 'total_births']
sum_births.to_csv('daily_births_sum.csv', index=False)
```
